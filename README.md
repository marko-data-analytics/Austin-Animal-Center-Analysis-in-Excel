Austin Animal Center Analysis

    Project Overview

        This project analyzes animal outcome data from the Austin Animal Center, downloaded form data.gov, using Microsoft Excel. The goal is to evaluate shelter         performance, animal outcomes, breed distribution, and euthanasia reasons.
        The dashboard provides insights into adoption outcomes, shelter duration, breed distribution, and euthanasia causes while demonstrating Excel-based               reporting and data visualization skills.

    Objectives

        Analyze the distribution of animal outcomes across the shelter population.
        Monitor outcome trends over time.
        Identify the most common animal breeds.
        Examine the primary reasons for euthanasia outcomes.
        Present findings through an interactive Excel dashboard using KPIs, charts, and slicers.

    Key Insights

        Adoption is the most common outcome, accounting for 48.67% of all animal outcomes.
        Transfer Out represents 30.08% of outcomes, making it the second most common disposition method.
        Animals spend an average of 239 days in the shelter before reaching an outcome.
        Domestic Shorthair is the most frequently occurring breed in the dataset.
        Suffering and Rabies Risk are the leading recorded reasons for euthanasia.
        Outcome volume declined during late 2025 and early 2026 before recovering in spring 2026.

    Technical Implementation

        Data Preparation: Standardized outcome categories to reduce fragmentation and improve reporting consistency.
        Data Analysis: Microsoft Excel using Pivot Tables, calculated metrics, and summary statistics.
        Dashboard Development: Interactive Excel dashboard with slicers, KPI cards, trend analysis, and outcome reporting.
        Visualization: Combination of column charts, line charts, and ranked bar charts to highlight key trends and performance indicators.
        Austin Animal Center-inspired color palette (#FBF5F2, #529C58, #474A96) for consistent and professional visuals.
